# Database Assistant

## Summary

Database Assistant is the DBN natural language assistant surface. It can generate SQL, explain database code, inspect metadata, use approved DBN tools, and answer questions in the `DB Assistant` tool window.

DBN supports two distinct assistant paths:

- **Oracle Select AI:** A database-native Oracle feature. Prompts are sent through the connected Oracle database using `DBMS_CLOUD_AI`, database AI profiles, database credentials, database network ACLs, and database privileges.
- **Generic Assistant:** A DBN-managed assistant. Prompts are sent from DBN to a configured language model provider using DBN project profiles, project credentials, assistant modes, built-in tools, tool approvals, and optional MCP servers.

> **Note:** The two paths share the `DB Assistant` user interface, but they do not share the same backend, profile storage, credential storage, prerequisites, or execution behavior.

## When To Use It

Use Database Assistant when you need to:

- Generate SQL from a natural language prompt.
- Ask questions about schemas, tables, views, programs, Java objects, open editors, or indexed content.
- Use Oracle Select AI against an Oracle database that supports `DBMS_CLOUD_AI`.
- Use a DBN-managed LLM provider for database-aware development, analytics, or `RAG` workflows.
- Control which assistant tools can read metadata, source code, editor content, result data, or external MCP tools.

Choose Oracle Select AI when the answer should be generated by the Oracle database feature itself. Choose the generic assistant when you want DBN to orchestrate a provider model, DBN tools, MCP tools, or vector-search retrieval from the IDE.

## Access Paths

- **DB Assistant tool window:** Open the `DB Assistant` tool window from the IDE tool window bar.
- **Assistant settings:** `DB Navigator` -> `Settings` -> `Assistant`, or `DB Assistant` toolbar -> `Settings...`.
- **Oracle Select AI profile setup:** `DB Assistant` toolbar -> `Profile Setup...` when Oracle Select AI is active.
- **Oracle Select AI editor actions:** SQL/PSQL editor context menu or Generate action -> `Select AI - Generate SQL` or `Select AI - Generate and Explain SQL`.
- **Generic tool approvals:** `DB Assistant` tool request prompt, `Tools`, `MCP Servers`, or `Tool Approvals...`.
- **RAG from Vector Toolbox:** Vector embedding result summary -> `Open Database Assistant`.

## Assistant Paths

| Assistant path | Where it runs | Configuration source | Typical use |
| --- | --- | --- | --- |
| Oracle Select AI | Inside an Oracle database that supports Select AI | Database AI profiles, database credentials, network ACLs, and `DBMS_CLOUD_AI` privileges | Natural language SQL generation and explanation grounded in profile-exposed database objects. |
| Generic Assistant | Inside DBN and the selected LLM provider API | DBN Assistant settings, project credentials, profiles, assistant modes, tool approvals, and MCP servers | Database-aware IDE assistance across metadata, source code, editors, datasets, external tools, and semantic search. |

## Choosing A Path

- **Use Oracle Select AI** when the organization has database-side Select AI profiles and wants prompts to run through Oracle's database-native `DBMS_CLOUD_AI` integration.
- **Use Generic Assistant** when DBN should call a configured provider directly and use DBN-managed tools, IDE context, MCP servers, or `RAG` mode.
- **Use Vector Toolbox with Generic Assistant** when answers should be grounded in an embeddings table created from files, tables, or queries.
- **Use Assistant Settings** when you need to configure provider credentials, generic profiles, MCP servers, tool approvals, or Select AI setup.

## Shared UI Concepts

The `DB Assistant` tool window keeps conversations tied to the selected connection and assistant path.

- **Connection context:** Determines which database the assistant can use.
- **Profile selection:** Chooses either a database Select AI profile or a generic DBN assistant profile.
- **Model selection:** Chooses the model available for the selected profile.
- **Chat controls:** `New Chat`, `Clear Chat`, `Chat History`, `Expand All`, `Collapse All`, and `Submit Prompt`.
- **Tool controls:** Generic assistant chats can show DBN built-in tools, MCP servers, and tool approval controls.

Changing profile, provider, model, or Select AI action can discard the current unsaved chat after confirmation.

## Common Workflows

### Choose The Assistant Path

1. Decide whether the request should run through Oracle database-native Select AI or through DBN's generic assistant.
2. Confirm the active connection supports the chosen path.
3. Open `DB Assistant`.
4. Select the relevant profile and model.
5. Review any tool, profile, or prerequisite prompts before sending the request.

### Open Detailed Documentation

1. Use the overview on this page to choose the assistant path.
2. Open the Oracle Select AI page for database-native profile, credential, and editor-action workflows.
3. Open the Generic Assistant page for provider profiles, assistant modes, DBN tools, MCP support, and `RAG`.
4. Open the settings overview, Generic Assistant Settings, or Oracle Select AI Settings for configuration details.

## Troubleshooting

| Symptom | Resolution |
| --- | --- |
| Unsure which assistant path to use | Use Oracle Select AI for database-native `DBMS_CLOUD_AI` workflows. Use the generic assistant for DBN-managed provider profiles, DBN tools, MCP servers, and `RAG`. |
| Oracle Select AI is unavailable | Confirm the connection is Oracle and supports Select AI, then review Oracle Select AI prerequisites. |
| Generic assistant has no profile | Create a DBN Assistant profile and credential in Assistant settings. |
| Expected assistant tools are missing | Check whether you are using the generic assistant, whether the selected mode supports the tool, and whether the tool is blocked. |
| `RAG` mode has no embedding table | Select an embeddings table from the generic assistant toolbar, or open the chat from a Vector Toolbox result. |
