# Database Assistant: Generic Assistant Settings

## Summary

Generic Assistant settings are DBN project settings. They configure the DBN-managed assistant path: provider credentials, assistant profiles, MCP servers, built-in tool approvals, MCP tool approvals, and semantic-search tool access for `RAG` mode.

| Setting area | Scope | Purpose |
| --- | --- | --- |
| Generic assistant credentials | Project | Store provider credentials used by DBN-managed assistant profiles. |
| Generic assistant profiles | Project | Configure provider, credential, temperature, and instructions for the generic assistant. |
| MCP servers | Project | Register external HTTP or STDIO MCP servers and optional IDE workspace integration. |
| Tool approvals | Connection and assistant state | Control which DBN and MCP tools the generic assistant may invoke. |
| Built-in tool controls | Assistant mode and connection context | Allow or block DBN metadata, source, editor, dataset, console, and semantic-search tools. |

## Access Paths

- **Assistant project settings:** `DB Navigator` -> `Settings` -> `Assistant`.
- **Generic assistant settings:** `DB Assistant` toolbar -> `Settings...`.
- **Generic tool approvals:** `DB Assistant` prompt/tool approval dialog, `Tools`, or `Tool Approvals...`.
- **MCP server configuration:** `DB Navigator` -> `Settings` -> `Assistant` -> `MCP Servers`.
- **MCP server selection:** `DB Assistant` toolbar -> `MCP Servers` in a generic `Development` or `Analytics` chat.

## Credentials

Credentials define how DBN authenticates with a language model provider.

- **`Name`:** Display name used in profile configuration.
- **`Provider`:** Provider family, such as OCI Generative AI, OpenAI, Google, Anthropic, Mistral AI, or X AI where supported.
- **`User`:** User field when required by the selected provider or credential type.
- **`Secret`:** API key, password, access token, or provider secret. Secret values are stored through DBN credential storage.
- **`OCI configuration`:** OCI-specific configuration such as config file/profile, user, tenancy, compartment, endpoint, runtime, and API format where required.

Use separate credentials when providers, accounts, compartments, or access policies differ.

## Profiles

Profiles define how the generic assistant should use a provider credential.

- **`Name`:** Display name shown in the `Select Profile` control.
- **`Provider`:** Language model provider used by the profile.
- **`Credential`:** Project credential used to authenticate with the provider.
- **`Temperature`:** Preset or custom value controlling response determinism and creativity.
- **`Instructions`:** Optional profile-specific guidance included with generic assistant prompts.

Temperature presets are:

- **`Precise`:** Favors accuracy and low variation.
- **`Balanced`:** Default general-purpose behavior.
- **`Exploratory`:** Allows more variation.
- **`Experimental`:** Allows the most creative behavior.
- **`Custom`:** Uses a manually selected temperature value.

DBN can also show implicit or potential profiles based on configured credentials and supported providers, so a provider can be selected before a fully declared profile exists.

## MCP Servers

MCP server settings expose external tools to the generic assistant.

- **`Name`:** Display name shown in Assistant settings and the `MCP Servers` selector.
- **`HTTP`:** Connects to an MCP server by URL.
- **`STDIO`:** Starts an MCP server from a local command and command arguments.
- **`Command preview`:** Shows the command line DBN will use for a `STDIO` server.
- **`Verify configuration`:** Checks whether DBN can connect to the server and load its tools.
- **`Tool approvals`:** Opens approvals for tools exposed by the selected MCP server.
- **Workspace integration:** Enables IDE MCP server integration when the IDE MCP Server plugin is installed and enabled.

A server generated by MCP Server Builder can be registered here after build, either as a `STDIO` command using the generated JAR or as an `HTTP` server using the generated local endpoint.

Only enable MCP servers you trust. External tools can expose workspace or service capabilities beyond DBN's built-in assistant tools.

## MCP Tool Approvals

MCP tool approvals are stored separately from DBN built-in tool approvals.

- **Server approval:** Approves or blocks all tools from an MCP server.
- **Tool approval:** Approves or blocks one tool exposed by a server.
- **`Prompted`:** Shows an approval prompt before the tool can run.
- **`Approved`:** Lets the tool run automatically when requested by the model.
- **`Blocked`:** Hides the tool from the model.

DBN asks you to trust an MCP endpoint before connecting to it. The trust prompt includes the server name, endpoint type, and endpoint value.

## Tool Approvals

Tool approvals control generic assistant access to DBN built-in tools. MCP tools use the separate MCP server and MCP tool approvals described above.

- **Allow once:** Allows the current tool request only.
- **Always allow:** Stores an approval for the built-in tool or tool category.
- **Deny:** Rejects the current tool request.
- **Disable tool:** Blocks future use of that built-in tool or tool category.

Built-in tool categories include user interaction, configuration information, metadata, source code, data, and IDE action invocation. Available tools depend on the assistant mode and connection context.

## Built-In Tool Controls

The `Tools` control in the generic assistant chat shows DBN built-in tools that are available for the selected assistant mode and connection.

| Built-in tool group | Main controls |
| --- | --- |
| User prompts | Keep interactive confirmation and decision tools prompted. |
| Configuration information | Allow or block access to connection information. |
| Metadata | Allow or block database, schema, table, view, program, and Java metadata tools. |
| Source code | Allow or block access to view, program, and Java source-code tools. |
| Data and retrieval | Allow or block semantic search tools in `RAG` mode for selected embeddings tables. |
| IDE actions | Allow or block tools that open data editors, SQL consoles, source editors, and Java editors. |

Interactive tools remain prompted. Blocking a tool category hides all tools in that category from the model.

## Validation Messages

| Message area | Common cause | Resolution |
| --- | --- | --- |
| Generic credential name | Name is empty or already used. | Enter a unique credential name. |
| Generic credential secret | API key, password, token, or OCI configuration is missing. | Provide the required provider credential fields. |
| Generic profile name | Name is empty or already used. | Enter a unique profile name. |
| Generic profile provider | No provider is selected. | Select a supported provider and model family. |
| Generic profile credential | No compatible credential is selected. | Select or create a credential for the chosen provider. |
| MCP server name | Name is empty or already used. | Enter a unique server name. |
| MCP HTTP server | URL is empty or invalid. | Provide the MCP server URL and verify the configuration. |
| MCP STDIO server | Command executable is missing. | Provide the command and optional arguments, then verify the configuration. |

## Troubleshooting

| Symptom | Resolution |
| --- | --- |
| Generic assistant cannot connect to provider | Check the selected profile, credential, provider API key, OCI configuration, IDE proxy settings, and network access. |
| Generic model list is empty | Confirm the selected profile has a provider and compatible credential, then reopen the model selector. |
| Generic assistant requests too many tools | Review `Tools` and `Tool Approvals...`, then block categories that should not be available. |
| MCP server verification fails | Check the URL for HTTP servers or the command and arguments for STDIO servers. Confirm the server can list tools. |
| MCP server trust prompt appears repeatedly | Confirm the server endpoint has not changed. DBN treats endpoint changes as a new trust decision. |
| MCP tools do not appear in chat | Select the server from `MCP Servers`, confirm the active mode is not `RAG`, and check that the selected model supports tools. |
| MCP tool is hidden | Check the server-level and tool-level approvals. Blocked MCP tools are not visible to the model. |
| Workspace integration reports MCP plugin missing | Install and enable the IDE MCP Server plugin, then return to Assistant settings. |
| `RAG` mode has no semantic-search tool | Confirm the connection supports vector search and the semantic-search tool is not blocked in `Tools`. |
